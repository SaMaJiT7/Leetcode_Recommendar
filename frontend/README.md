# CodeChallenge Daily - Frontend

A modern React frontend for the daily coding challenge platform.

## Features

- 🎯 Daily personalized coding challenges
- 💻 Monaco code editor with syntax highlighting
- 🔄 Multiple language support (Python, Java, C++)
- 🤖 AI-powered hints and feedback
- 📊 Real-time code execution results
- 🎨 Modern, responsive UI design

## Setup

1. Install dependencies:
```bash
npm install
```

2. Set the API URL (optional, defaults to http://localhost:8000):
Create a `.env` file:
```
REACT_APP_API_URL=http://localhost:8000
```

3. Start the development server:
```bash
npm start
```

The app will open at http://localhost:3000

## Build for Production

```bash
npm run build
```

This creates an optimized production build in the `build` folder.
